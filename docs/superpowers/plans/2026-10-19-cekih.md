# Aturan Cekih Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambahkan aturan cekih: pemain yang tinggal satu kartu lagi untuk tutup boleh menyebut cekih ke pemain lain, dengan bonus dan hukuman sesuai spesifikasi cekih.

**Architecture:** Logika cekih ditaruh di modul pure baru `src/rules/cekih.ts` yang beroperasi pada `RoundState`. `RoundState` mendapat field pelacak (pemilik kartu buangan, pernah mengambil dari buangan, pengambilan giliran ini, dan daftar cekih). Saat penutupan, `checkClosed` menentukan bonus dan hukuman. Server hanya meneruskan dua intent baru ke engine, dan UI menampilkan tombol serta pemberitahuan.

**Tech Stack:** TypeScript (engine pure), Vitest, Next.js (UI), Cloudflare Worker (server, tidak berubah strukturnya).

**Spec:** `docs/superpowers/specs/2026-10-19-cekih-design.md`, dengan aturan lengkap di `Spesifikasi Aturan Remi Indonesia.md`.

## Global Constraints

- Tutup tangan (tidak pernah mengambil dari buangan di ronde ini): +250, tanpa efek cekih.
- Tutup biasa: tidak ada bonus kecuali cekih aktif yang cocok.
- Bonus penutup dan hukuman pemain tercekih hanya terjadi jika kartu yang diambil pada giliran penutupan termasuk kartu yang dibuang pemain tercekih. Nilainya 10× nilai dasar kartu penutup.
- Hanya satu hukuman per penutupan, dari cekih milik pemain penutup.
- Cekih boleh dibatalkan kapan saja sampai ronde selesai.
- Nilai dasar mengikuti `baseValue` di `src/rules/cards.ts`. Joker dihitung dengan nilai dasarnya.

## Review Focus

1. Menyebut cekih saat tangan belum tinggal satu kartu lagi harus ditolak, dengan `CEKIH_NOT_ALLOWED`.
2. Membatalkan cekih yang tidak ada harus ditolak, dengan `CEKIH_NOT_FOUND`.
3. Penutupan tutup biasa yang mengambil kartu dari pemain lain (bukan pemain tercekih) tidak boleh memberi hukuman.
4. Dua cekih ke pemain yang sama dari pemain berbeda: hanya cekih pemain penutup yang dihitung.
5. Pemain yang pernah mengambil dari buangan di ronde ini tidak boleh dapat bonus tutup tangan 250, walaupun penutupannya dari cangkulan.

// src/rules/cekih.ts
import { makeDeck, type Card, type Rank } from "./cards";
import { canPartition } from "./partition";

// Tangan tinggal satu kartu lagi jika ada kartu X dari dek dan satu kartu c di tangan,
// sehingga tangan setelah ditambah X dan dikurangi c bisa dibentuk seluruhnya menjadi kombinasi.
export function canCallCekih(hand: Card[], jokerRank: Rank | null): boolean {
  for (const extra of makeDeck()) {
    const pool = [...hand, extra];
    for (let i = 0; i < pool.length; i++) {
      const rest = pool.filter((_, j) => j !== i);
      if (canPartition(rest, jokerRank)) return true;
    }
  }
  return false;
}
```

import type { PlayerId, RoundState } from "./turn";

export function callCekih(state: RoundState, caller: PlayerId, target: PlayerId): RoundState {
  if (state.result !== null) throw new Error("ROUND_OVER");
  if (caller === target) throw new Error("CEKIH_SELF");
  const exists = state.cekih.some((c) => c.caller === caller && c.target === target);
  if (exists) throw new Error("CEKIH_ALREADY_ACTIVE");
  if (!canCallCekih(state.hands[caller], state.jokerRank)) throw new Error("CEKIH_NOT_ALLOWED");
  return { ...state, cekih: [...state.cekih, { caller, target }] };
}

export function cancelCekih(state: RoundState, caller: PlayerId, target: PlayerId): RoundState {
  if (state.result !== null) throw new Error("ROUND_OVER");
  const exists = state.cekih.some((c) => c.caller === caller && c.target === target);
  if (!exists) throw new Error("CEKIH_NOT_FOUND");
  return {
    ...state,
    cekih: state.cekih.filter((c) => !(c.caller === caller && c.target === target)),
  };
}
```

   export function checkClosed(state: RoundState, player: PlayerId, card: Card): RoundResult | null {
     const rest = removeCards(state.hands[player], [card]);
     if (!canPartition(rest, state.jokerRank)) return null;
     // Tutup tangan: tidak pernah mengambil dari buangan di ronde ini.
     if (!state.pickedFromDiscard[player]) {
       return { closedBy: player, bonus: CLOSED_FROM_STOCK_BONUS, closingCard: card, cekihTarget: null, cekihPenalty: 0 };
     }
     // Tutup biasa: bonus dan hukuman hanya lewat cekih yang cocok.
     const target = matchingCekihTarget(state, player);
     if (target === null) {
       return { closedBy: player, bonus: 0, closingCard: card, cekihTarget: null, cekihPenalty: 0 };
     }
     const amount = CEKIH_MULTIPLIER * baseValue(card.rank);
     return { closedBy: player, bonus: amount, closingCard: card, cekihTarget: target, cekihPenalty: -amount };
   }

   // Pemain penutup harus punya cekih aktif ke pemain yang kartunya ikut diambil pada giliran ini.

     }
     return null;
